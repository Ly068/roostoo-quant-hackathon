# Team48-Y · 时序动量趋势跟踪交易系统

**APAC Quant Trading Hackathon 2026 · The University of Hong Kong**

一个完全自主、7×24 运行的加密货币量化交易系统，在 25 个高流动性加密货币上
通过**时序动量（只做多趋势跟踪）**参与上升趋势，并在无趋势时自动转为现金避险。

---

## 一、核心策略

### 1. 时序动量 / 趋势跟踪（Time-Series Momentum）

**逻辑：** 每个再平衡时点，对每个币种比较"现价"与"30 天前价格"：

```
若 现价 > 30天前价格（过去30天处于上升趋势）→ 纳入做多池
做多池内所有币种等权，总多头敞口 100%
无任何币种满足 → 100% 现金，自动避险
每 72 小时（3 天）根据最新趋势更新
```

**为什么只做多、不做空：**
- 加密市场有长期上涨偏差
- 做空弱势山寨币在轮动市极易被空头挤压（24h 内可暴涨 30%~50%）
- 实测多空横截面动量在 6–10 月上涨轮动市亏损（-18%），故放弃空头

**为什么"无趋势空仓"：**
- 时序动量在震荡/下跌市会因假趋势反复止损（动量崩溃）
- 空仓机制让组合在无上升趋势时不硬扛，天然控制下行

### 2. 动态仓位（比赛阶段自适应）

| 阶段 | 天数 | 仓位系数 | 目的 |
|------|------|---------|------|
| 观察期 | 1-3 | 60% | 开局谨慎，验证信号 |
| 确认期 | 4-10 | 100% | 满仓进攻，主力收益期 |
| 收尾期 | 11-14 | 70% | 锁定利润，降低末期风险 |

## 二、风控体系（独立 RiskManager 模块）

| 层级 | 规则 | 动作 |
|------|------|------|
| 单标的止损 | 相对开仓价反向偏离 **10%** | 立即单独平仓，不死等72h |
| 日回撤熔断 | 日内回撤 >4% / >8% | 减仓预警 / 全部平仓暂停1h |
| 连亏熔断 | 连续亏损 3 笔 | 暂停 30 分钟 |
| 敞口约束 | 总敞口 ≤100%（1x，无杠杆） | 硬约束 |

## 三、回测与稳健性验证

数据：**Binance 公共 1h K线**（volume 完整、价格真实），手续费 **0.1%/边**，72h 调仓。

### 三段独立窗口（互不重叠，每段约29天）

| 窗口 | 市场状态 | 收益 | Sharpe |
|------|---------|------|--------|
| 段1（7月） | 震荡下跌（25币均-5.5%） | **-4.8%** | -1.3 |
| 段2（8月） | 普涨（均+22.8%） | **+23.5%** | +4.7 |
| 段3（9月） | 山寨季（均+36.2%） | **+40.5%** | +6.4 |

全周期（120天）：**+65.4%，Sharpe 12.4，最大回撤 -13.4%**。

**诚实说明：**
- 历史高 Sharpe 是"恰好包含两段强趋势行情"的产物，**不能外推、不能承诺**
- 策略本质是**非对称**：震荡/下跌月下行约 -5%（靠空仓+止损控制），上涨月充分参与
- 若 14 天比赛持续无趋势，可能不赚或小亏——这是所有方向性策略的共同不确定性

### 防未来数据泄漏

- 回测引擎逐根 K 线推进，策略只能看到 t 及之前数据（`iloc` 截断）
- 信号、再平衡、止损均按时间顺序；冷启动数据截止于比赛开始前
- 已通过多轮数据审计（含识别并弃用 volume 缺失的数据源）

## 四、数据架构（信号源与执行场所分离）

Roostoo 仅提供实时 ticker、无历史 K 线，30 天窗口无法在 14 天内靠实盘积累：

- **冷启动**：部署时携带 Binance 预下载的 120 天数据（`data/history_binance`）
- **运行时**：每小时用 Binance 公共K线增量追加（volume 完整、与Roostoo价格一致）
- **执行前**：用 Roostoo 实时行情过滤，只在当前有报价币种中选币
- **执行**：Roostoo 负责下单、持仓核对与风控

```
├── dashboard/app.py            # Streamlit 监控 Dashboard
├── rooster_trader/
│   ├── client.py               # Roostoo REST API 封装
│   ├── execution.py            # 执行引擎（调仓+精度+全平）
│   ├── data/binance_feed.py    # Binance K线增量feed
│   ├── risk/manager.py         # 风控模块
│   ├── backtest/engine.py      # 事件驱动回测引擎（含止损）
│   └── strategy/
│       ├── trend.py            # 时序动量趋势跟踪（核心）
│       └── dynamic_position.py # 动态仓位包装
├── data/history_binance/       # Binance 120天历史（冷启动）
└── scripts/                    # 回测、网格、审计、赛前检查脚本
```
